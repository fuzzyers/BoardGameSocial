# BoardGameSocial

BoardGameSocial is a social platform designed to help organize and manage board game groups and communities.

The project was built around my own needs as a board game player, with the goal of making it easier for a community of players to organize events, communicate, manage their shared game collection, and keep track of what they play.

## Features

- **Groups** — Create and manage board game groups and their members.
- **Events** — Organize upcoming board game sessions and keep all the relevant information in one place.
- **Game Collections** — Maintain a shared collection of the games available to the group.
- **Game Polls** — Vote on which games should be played at upcoming events.
- **Chat** — Communicate with other members through group chat.
- **Game Results** — Record results from games played at events and build towards a larger player ranking and statistics system.
- **Player Profiles** — Create profiles with information about players and their favourite games.
- **BoardGameGeek Import** — Quickly import board games into the collection using the BoardGameGeek XML API.

## Purpose

The project started as a way to solve a problem within my own board game community. Rather than relying on several different services to organize events, communicate with players, decide what games to play, and keep track of results, BoardGameSocial aims to bring these features together into one platform.

The results system is also being designed to grow beyond simply recording event results. The long-term goal is to build a broader statistics and ranking system that can track player performance across games and events.
